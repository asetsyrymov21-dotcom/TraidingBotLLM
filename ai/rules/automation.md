# Automation Rules — Trading Bot

## Automation mode (бот работает сам, агент мониторит)
- Только диагностика — не менять торговую логику
- Собирать доказательства из логов
- Сообщать вероятную причину проблемы
- Не останавливать бота без явного запроса пользователя

## Что проверять автоматически
1. Статус сервиса: `systemctl status tradingbot`
2. Последние ошибки: `journalctl -u tradingbot | grep -E 'ERROR|Traceback' | tail -20`
3. Авто-деплой: свежий ли код на VPS (`git log --oneline -3`)
4. Торгует ли бот: есть ли INFO-логи за последние 2 минуты

## Required output при проблеме
1. Что проверено
2. Что найдено (с цитатой из логов)
3. Вероятная причина
4. Предлагаемый ручной фикс (без автоматического применения)

## Forbidden
- Менять стратегии / параметры без запроса
- Останавливать/перезапускать сервис самостоятельно
- Деплоить код в automation-режиме
